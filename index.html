Set up Apple Shortcuts

1 Install the Home Screen app

Open this site in Safari → Share → Add to Home Screen. Launch Rage Tracker from its new icon, then pair it using the code provided with your setup.

2 Start with Health steps

In Apple's Shortcuts app, create a shortcut named Rage Tracker · Steps.

  1. Add Find Health Samples. Filter to Step Count dated today.
  2. Add Calculate Statistics; choose Sum for the sample values. Some iOS versions may require extracting sample values first.
  3. Add Current Date and Format Date with custom format yyyy-MM-dd.
  4. Add Get Contents of URL using the request URL above. Choose POST and request body Form. Add fields kind=health, date=formatted date, steps=calculated sum.
  5. In Headers, add Authorization with the exact copied header value. Run it and accept Health permissions.

When this works, you can make similar shortcuts for sleepHours, hrv, or workoutMin. Each updates only the metric you send for that day.

3 Add calendar events

Create another Shortcut, Rage Tracker · Calendar.

  1. Use Find Calendar Events for today.
  2. Add Repeat with Each event.
  3. Inside the repeat, use Get Details of Calendar Events for its title, start, and end. Format dates to ISO 8601 if your iOS version offers it.
  4. Inside the repeat, add Get Contents of URL → POST → Form, with kind=calendar, title=event title, start=start date, end=end date, category=Meeting. Add the copied Authorization header.

For better privacy, omit title and send a category instead; the server will label it “Calendar event”. Test a single event before enabling repetition.

4 Automate it

In Shortcuts → Automation, add a Time of Day trigger and select the shortcut. Choose Run Immediately where offered. Start with once per day; add more triggers if useful. Automatic execution and Health permission prompts vary by iOS version. Open Rage Tracker and tap Sync now to fetch updates.

What goes to Cloudflare?

Only the fields your Shortcuts send, such as step totals and event times/titles. Mood entries and notes remain on your iPhone. The synced information is stored in your Bishvili Cloudflare account and can be erased below. This is not end-to-end encrypted.

About the insights
