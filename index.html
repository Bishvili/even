Guided Shortcut setup

1 Sign in and copy your private key

Open Rage Tracker from your iPhone Home Screen. Tap Continue with email, enter an approved address on Cloudflare's login page, and enter the one-time code emailed to you. Return here, tap Generate my device key, and copy the Authorization header shown above.

2 Create one Health Shortcut

Open Apple Shortcuts and create Rage Tracker · Health. Select just a few metrics to start:

  1. Find Health Samples → Step Count → today; use Calculate Statistics → Sum for the sample values, extracting values first if needed.
  2. Format Date for today's date with custom format yyyy-MM-dd.
  3. Get Contents of URL → the copied sync endpoint → POST → body Form.
  4. Fields: kind = health, date = formatted date, steps = summed steps.
  5. Header Authorization = the exact copied value. Run once and approve Health permissions.

When it works, add sleepHours, hrv, or workoutMin as you prefer. Shortcuts options vary by iOS version.

3 Add Calendar events

In the same Shortcut, add Find Calendar Events for today, then Repeat with Each event.

  1. Read the event's title, start and end using Get Details of Calendar Events.
  2. For each event, Get Contents of URL using the same endpoint, method POST, body Form.
  3. Fields: kind = calendar, title = event title, start = start date, end = end date, category = Meeting. Use ISO 8601 dates with time zones where possible.
  4. Use the same Authorization header. You can omit titles and send just event times/categories if you prefer.

Alternatively, a single JSON request can send {"kind":"batch","health":[...],"events":[...]}, which we'll use in the future shared Shortcut.

4 Automate and check the connection

In Shortcuts → Automation, use a Time of Day trigger for your Shortcut and select Run Immediately if offered. Automatic execution and permission dialogs vary by iOS version. Return here and tap Sync now. Only the signed-in owner's data will be returned.

Privacy and control

Mood check-ins remain on this phone. Selected Health measurements and Calendar data are sent over HTTPS and stored in owner-specific Cloudflare database records. Access uses email one-time PIN; device keys are revocable. Data is not end-to-end encrypted. Back up your local data before switching accounts.
